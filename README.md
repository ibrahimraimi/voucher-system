# Secure Voucher System

A robust, secure, and observable voucher code generation and redemption system. This system is designed for high-integrity applications such as airtime recharge, gift cards, or promo codes.

## Features

- **Cryptographically Secure PINs**: 16-digit PINs generated using `crypto/rand`.
- **Integrity & Authenticity**:
  - **Luhn Checksum**: Instant validation of PIN format.
  - **HMAC Signature**: Verifies that the PIN was generated by this system (preventing brute-force attacks).
- **Security First**:
  - **SHA-256 Hashing**: PINs are hashed before storage.
  - **Timing Attack Protection**: Constant-time hash comparison.
  - **Abuse Protection**: In-memory rate limiting and exponential backoff.
- **Concurrency Safe**: Atomic database transactions and double-spending protection.
- **Observability**: Real-time metrics for generation, redemption, and failures.

## Quick Start

### Prerequisites
- Go 1.21+
- SQLite3 (embedded)

### running the Application

The `main.go` entry point runs a demonstration of the system, including batch generation and a metrics dashboard.

```bash
go run cmd/voucher-system/main.go
```

### Running Tests

Run the comprehensive test suite, including race condition detection:

```bash
go test -race -v ./...
```
